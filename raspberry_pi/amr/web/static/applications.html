What this page is

A read-only directory of the interfaces in this repository, rendered from GET /applications/state. Each card carries the status it has right now; the declared baseline lives in config/applications.yaml. Runtime conditions may make a status worse, never better: a camera that is not attached cannot be reported as a working camera.

This page issues GET requests only. Nothing here can command the robot, and a card that can command motion says so on its face.

Start here

  1. Open a terminal in the raspberry_pi/ folder.
  2. Run python -m amr.main --mock --web and leave it running.
  3. Click a link below — this page refreshes itself as the robot changes.

--mock means nothing touches real hardware. Drop both flags to run against a real robot, but read the README first: the hazard and safety layers are off by default and their thresholds are unverified.
